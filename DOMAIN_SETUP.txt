# Custom domain checklist — nikshay.xyz
#
# You must do these in the dashboards (cannot be automated from this repo):
#
# 1) Render → Web Service → Settings → Custom Domains
#    Add: api.nikshay.xyz
#    Copy the CNAME target Render shows.
#
# 2) Vercel → Project → Settings → Domains
#    Add: nikshay.xyz and www.nikshay.xyz
#    Copy the DNS records Vercel shows.
#
# 3) DNS at your registrar for nikshay.xyz
#    - CNAME  api  →  (Render CNAME target)
#    - Apex / www →  (exactly as Vercel instructs)
#
# 4) Vercel → Settings → Environment Variables
#    VITE_API_URL = https://api.nikshay.xyz
#    Then Redeploy Production.
#
# 5) After DNS + certs are live:
#    https://api.nikshay.xyz/health
#    https://nikshay.xyz
#
# 6) Phone: uninstall old app, install new APK from portal Download.
